Active in-game codes

How to redeem codes in Infinite Magicraid

  1. Open Infinite Magicraid (phone or PC client) and finish the tutorial if you're a new player.
  2. Tap your profile picture in the top-left corner.
  3. Open Settings.
  4. Tap Redeem Code.
  5. Paste or type the code exactly as shown, then tap Confirm.
  6. Collect your rewards from your in-game mail / reward box.

Code not working?

  • Check the spelling and capital letters. Codes must match exactly. Copying from this page avoids typos.
  • Already used? Each code can only be redeemed once per account.
  • Expired? Monthly and event codes usually end on the last day of the month or event. Check the dates above.
  • Server or account limits. Some codes are only for certain servers or for new accounts.
  • If you still get "Invalid Redeem Code", restart the game and try again.

New codes usually arrive each month (a monthly gift code), on holidays and events, at the game's anniversary, and through creator and Discord giveaways. Bookmark this page. We update it as new codes drop.
